# NosoNode: The Decentralized Network of Noso

NosoNode is a high-performance, open-source blockchain project designed for efficiency, transparency, and accessible decentralization. Built from the ground up to avoid the pitfalls of centralized mining and complex barrier-to-entry systems, Noso provides a robust ecosystem for value transfer and protocol service hosting.

## 🚀 Key Features

### 1. Fair Distribution & Mining
Noso utilizes a customized Proof-of-Work (PoW) algorithm designed to be ASIC-resistant, ensuring that everyday users can participate in network security and reward distribution using standard hardware.

### 2. Dual-Layer Rewards (PoW + PoS)
The network incentivizes both security and service:
- **Miners**: Use hashing power to secure the chain and generate new blocks.
- **Masternodes (PoS)**: High-availability servers that provide protocol services (verification, P2P routing) in exchange for a portion of the block reward.

### 3. Global Virtual Tokens (GVT)
A unique limited-supply asset (only 100 in existence) that grants holders specialized voting rights and protocol-level governance over project funds.

### 4. Zero-Dependency Core
Implemented in Pascal for maximum control and performance, the NosoNode code handles its own P2P stack, cryptographic primitives, and database management without relying on bloated external frameworks.

## 💎 Tokenomics

- **Total Supply**: Limited supply with a gradual halving mechanism.
- **Block Time**: 600 seconds (10 minutes).
- **Consensus**: Hybrid PoW/PoS for maximum decentralization.
- **Fees**: Designed to be predictable and low, ensuring the network remains usable for micro-transactions.

## 🛠 Technical Advantages

- **Self-Contained Persistence**: Uses a custom binary indexing system (Summary index) for O(1) balance retrieval, even as the blockchain grows.
- **Interactive Console**: A built-in CLI within the node allows for real-time monitoring and administrative control.
- **Adaptive Networking**: The protocol dynamically adjusts to peer availability and network latency for stable performance.

## 🌍 Vision
Noso aims to become the most accessible desktop-first cryptocurrency, where any user can run a full node, mine with their available hardware, and participate in a truly decentralized digital economy.
