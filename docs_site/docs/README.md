# NosoNode Documentation Bundle

Welcome to the NosoNode technical documentation. This collection of documents provides a deep dive into the architecture, protocol, and design philosophy of the current node implementation.

## Documents

- [**Architecture Overview**](ARCHITECTURE.md): System components, module structure, and high-level interaction diagrams.
- [**Cryptographic Schematics**](CRYPTO.md): Address generation, signing, and PoW flows.
- [**API Reference**](api/): Detailed documentation for every Pascal module (Networking, Logic, RPC, etc.).
- [**File Reference**](FILES.md): Detailed mapping of every source file and its responsibility.
- [**Data Structures**](DATA_STRUCTURES.md): Specification of transactions, blocks, and masternode records.
- [**Logic Flows**](LOGIC_FLOWS.md): Deep dive into consensus, block building, and sync logic.
- [**Protocol Specification**](PROTOCOL.md): Detailed look at the P2P communication and message formats.
- [**Design Decisions & Technical Debt**](DESIGN_DECISIONS.md): Analysis of implementation choices and lessons learned.

## Project Context
This documentation was generated to preserve the knowledge and "pain points" of the legacy Pascal codebase before embarking on a new project.
